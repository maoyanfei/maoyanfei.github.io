🎯 项目背景

业务现状

野村证券 Wholesale 全球市场部（GM）主营股票、跨境衍生品等机构交易业务，业务团队需高频监控市场行情与交易数据。

核心痛点

  • 数据分散，来源不统一，缺乏统一口径
  • 依赖人工汇总，流程低效，耗时耗力
  • 同步滞后，无法支撑实时交易决策
  • 无法满足风险监控及业务复盘需求

解决方案

✅ 搭建标准化、自动化的金融数据可视化看板体系，统一数据口径，实现分钟级实时更新，为全球机构交易业务提供精准数据支撑。

👨‍💻 核心职责与贡献
①
BI 报表体系搭建
搭建全维度证券交易行情报表体系，覆盖昨收/今开、日内高低价、涨跌幅、成交量、成交额等基础指标，拓展盘口流动性、机构持仓等高阶维度。
②
数据链路自动化
完成数据抽取、清洗、转换、建模全流程开发，优化同步逻辑，实现行情数据分钟级自动更新，搭建数据校验规则。
③
可视化与交互优化
面向交易员、风控、管理层等核心用户，适配做市、跨境交易业务场景，优化图表展示、多维筛选功能。
④
运维支撑与迭代
负责报表日常运维与问题快速响应，保障 7×24 小时跨时区交易数据服务稳定，持续迭代新增功能。
📈 项目成果 & 业务价值
自动化替代 - 搭建自动化金融行情 BI 报表体系，替代传统人工 Excel 汇总，缩减 60%+ 数据整理工时，显著提升交易团队工作效率
实时性优化 - 落地标准化数据校验与更新机制，将数据延迟从小时级优化至分钟级，为做市报价、日内交易、风险对冲提供精准实时数据支撑
业务支撑 - 完善多维可视化分析能力，助力团队高效完成市场研判、交易复盘与流动性风控，有效支撑二级市场交易、结构化衍生品等核心业务落地
全球覆盖 - 适配跨境机构交易场景，支撑全球机构业务，实现跨时区交易数据的统一管理与实时更新
💡 个人成长与收获

职业发展的转折点

这个项目标志着我从参与项目到独立负责项目的成长蜕变。2021 年进入野村后，我获得了前所未有的信任和话语权，在技术选型、架构设计、开发流程、项目迭代等诸多方面实现了职业发展的跨越。这是我从初级工程师向高级工程师发展过程中最重要的里程碑。

技术深度与广度

  • 后端技术 - 选择 Python 作为主力语言，深入学习其数据处理优势
  • 数据工程 - 接触多源数据库、ETL 全流程，完成复杂的数据建模
  • BI 平台 - 深入学习 Power BI 报表开发，掌握从需求到上线的完整流程
  • 架构思维 - 在金融交易场景中实践系统性设计和问题解决能力

国际化协作能力

野村全球化的工作环境让我与来自印度、美国、日本等不同国家的团队成员紧密协作。部门领导来自印度，项目经理来自美国，产品、运维等团队成员来自世界各地。通过全英文工作场景，我不仅提升了语言沟通能力，更重要的是学会了在跨文化背景下的有效沟通与协调，这成为了我职业生涯中最宝贵的财富。
